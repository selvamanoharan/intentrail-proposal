# IntentRail A2A extension proposal

IntentRail is a discussion draft for an A2A lifecycle extension that binds:

1. what was requested;
2. what was authorized;
3. what was executed; and
4. what outcome was observed.

Read the full proposal at:

**https://selvamanoharan.github.io/intentrail-proposal/**

The implementation repository remains private while security hardening is
completed. This repository contains proposal material only.

## Status

Community discussion draft. We intend to request review and, if A2A maintainers
agree with the scope, sponsorship for an `experimental-ext-intentrail`
repository.
